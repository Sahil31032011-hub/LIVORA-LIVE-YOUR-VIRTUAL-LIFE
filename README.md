# LIVORA — Live Your Virtual Life

A lightweight browser-based virtual-life town game. The current early build runs on desktop, tablet, and mobile without an installation.

## Play
Enable GitHub Pages for this repository:
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. After GitHub Pages finishes publishing, open the Pages URL shown in Settings → Pages.

## Controls
- **Mobile:** use the on-screen joystick.
- **Desktop:** WASD or arrow keys.
- **TALK:** speak with a nearby resident.
- **WORK:** earn 50 coins.
- **HOME:** return to your home.
- **DANCE:** show a dance message.

## Current features
- Scrollable town with roads, buildings, trees, residents, and moving cars.
- Mobile joystick and touch action buttons.
- Keyboard movement.
- Day/night lighting, in-game clock, coins, and level display.

This is an early 2D prototype, not yet a full 3D simulation.
